# 情绪模型定义

本文件是 `mood_analyzer.py` 中情绪引擎的数学规范。修改评分逻辑时，本文件与脚本需同步更新。

## 1. 情绪总分 mood_score（0-100）

情绪分由四个维度加权合成，**分数越高代表情绪性越强**（注意：不是"心情越好"）：

| 维度 | 权重 | 计算方式 |
|---|---|---|
| 深夜因子 `S_night` | 30% | 订单时间落在 22:00-02:00 记满分，20:00-22:00 线性衰减 |
| 高糖高脂因子 `S_indulge` | 30% | 当日甜品类热量占比 + 脂肪供能比 |
| 金额冲动因子 `S_spend` | 25% | 当日总额 / 30 天客单价，超过 2 倍满分 |
| 频次因子 `S_freq` | 15% | 当日订单笔数，1 笔 0 分，≥3 笔满分 |

`mood_score = 0.30·S_night + 0.30·S_indulge + 0.25·S_spend + 0.15·S_freq`

## 2. 分段标签

| 区间 | 标签 tag | 解读基调 |
|---|---|---|
| 0-25 | 平静日常 | 稳定输出 |
| 26-45 | 轻度放纵 | 犒劳自己 |
| 46-65 | 压力求安慰 | 压力偏大 |
| 66-82 | 情绪性进食 | 建议缓一缓 |
| 83-100 | 深夜崩溃局 | 关心睡眠为主 |

## 3. 触发因子识别

因子在模型中参与打分，同时在报告中必须**点名具体餐品**，禁止只给抽象结论。

| 因子 | 判定条件 |
|---|---|
| 🕐 深夜下单 | `22:00 ≤ hour < 02:00` |
| 🍟 高糖高脂组合 | 同日同时存在「甜品类」且「甜品热量 / 当日总热量 > 25%」 |
| 💸 大额冲动单 | 单笔金额 > 30 天客单价 × 2 |
| 🔁 高频连单 | 单日订单数 ≥ 2 |

## 4. 餐品情绪色彩分类

用于"点了什么"→"想表达什么"的映射，脚本内置关键词匹配（见 `CATEGORY_RULES`）。

| 类别 | 关键词样例 | 情绪色彩 | 营养关注点 |
|---|---|---|---|
| 甜品 dessert | 新地、派、麦旋风、圣代、奶昔 | 安慰、犒赏 | 糖、脂肪 |
| 炸物 fried | 麦乐鸡、薯条、鸡翅、鸡块、脆鸡 | 解压、满足 | 脂肪、钠 |
| 主食 burger | 巨无霸、汉堡、麦满分、三明治 | 能量补充、常规 | 能量、钠 |
| 饮品 drink | 可乐、雪碧、咖啡、奶昔、奶茶 | 提神、解渴 | 糖、咖啡因 |
| 轻食 light | 沙拉、玉米杯、苹果片、纯牛奶 | 自律、健康 | 蛋白质、钙 |

**品类失衡判定**：若甜品 + 炸物合计热量占比 > 60%，标记 `heavy_indulgence`。

## 5. 环比与趋势

- `mom_change` =（本月支出 - 上月支出）/ 上月支出 × 100%
- 预测采用近 3 个月线性外推；样本 < 2 个月时不做预测，输出"数据积累中"。

## 6. 调参原则

1. 阈值必须**基于真实订单数据**调整，不得拍脑袋。
2. 任何权重调整都需在本文件留痕，便于复核。
3. 情绪结论一律标注"基于订单推测，非心理诊断"。
